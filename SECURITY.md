# Security policy

This is a personal homelab repository. It is configuration for my own
infrastructure, not a supported product, and only the `main` branch is
maintained.

## Reporting a vulnerability

Report problems privately through GitHub's
[private vulnerability reporting](https://github.com/nlopez/homelab/security/advisories/new)
instead of opening a public issue or pull request.

Useful reports include:

* A credential, token, or private key committed to this repository.
* A workflow or configuration here that could be abused, for example to run
  untrusted code in CI or to reach my infrastructure.

I will acknowledge a report when I see it, but this is a hobby project with no
response-time commitment.
